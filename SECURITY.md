# Security

## Reporting Vulnerabilities

If you discover a security issue in Treslibre for Desktop, please report it responsibly via GitHub
Security Advisories at <https://github.com/Treslibre/treslibre-desktop/security/advisories/new> (or
open an issue at <https://github.com/Treslibre/treslibre-desktop/issues> if the issue is already
public).

Please include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- The version or commit hash affected.
